\# Problem Statement: Phase-Aware SAR Target Classification



\## Problem

Conventional deep learning approaches to SAR image classification reduce multi-look or single-look complex data to scalar intensity/magnitude images. This strips away essential relative phase relationships generated by radar scattering mechanisms.



\## Objective

Develop and evaluate a complex-valued convolutional neural network (CV-CNN) pipeline that directly processes complex-valued SAR signatures. The model will leverage explicit magnitude-phase activation mappings and undergo rigorous benchmark evaluation on standard dataset splits (SOC $17^\\circ \\rightarrow 15^\\circ$).
